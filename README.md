# Цифровой сотрудник для анализа качества RAG-системы

## Описание проекта

Цифровой сотрудник представляет собой систему автоматизированной оценки качества RAG (Retrieval-Augmented Generation), предназначенную для анализа эффективности поиска релевантной информации, оценки качества сгенерированных ответов, выявления ошибок и формирования рекомендаций по совершенствованию RAG-пайплайна.

## Цель проекта

Разработка универсальной системы оценки качества RAG, независимой от конкретной архитектуры анализируемой системы и предметной области ее применения.

## Основные задачи

1. Оценка качества поиска документов (Retrieval).
2. Оценка качества сгенерированных ответов (Generation).
3. Автоматическая классификация ошибок с использованием системы тегов.
4. Оценка согласованности автоматической и экспертной разметки.
5. Разработка адаптера для преобразования результатов работы RAG в единый формат входных данных.
6. Формирование структурированных отчетов в форматах JSON и Excel.
7. Диагностика узких мест RAG-пайплайна и генерация рекомендаций по его улучшению с использованием LLM.
8. Анализ качества, производительности, стоимости и практической эффективности разработанной системы.

## Входные данные

Единый файл на основе формата Qrels, расширенного для оценки этапа генерации.

## Выходные данные

1. JSON-отчет с рассчитанными метриками.
2. Excel-отчет с результатами оценки Retrieval и Generation.
3. Итоговая оценка качества RAG-системы.
4. Рекомендации по устранению выявленных недостатков.

## Статус проекта
